# Reporting Summary Notes

This file is the staging area for Nature Portfolio-style life-science reporting details.

Capture at least:

- study objective and hypothesis framing
- dataset provenance and preprocessing choices
- inclusion / exclusion rules
- replication structure or fold structure
- model selection and stopping criteria
- statistics and primary evaluation metrics
- software environment, provider chain, and fallback behavior
- failure handling, review loops, and notebook repair policies

For notebook-based analyses, also note:

- whether the run was generated, reviewed, executed, or externally repaired
- the exact `trial_dir`
- whether a degraded notebook or fallback provider path was used
- whether review reports or notebook fixes changed the scientific conclusion
