# Data Availability

Use this file to draft the manuscript-ready data availability statement.

Populate or update:

- dataset name(s)
- repository target
- accession / DOI / persistent URL
- whether data are openly released or controlled access
- any access restrictions and why they exist
- what minimal data subset is required to reproduce the main results

Recommended structure:

1. Publicly available datasets used in this study
2. Derived or curated analysis files generated in this work
3. Controlled-access or restricted materials, if any
4. Reproduction subset needed for the main figures/tables
